# Fleur Océan

Site vitrine en HTML, CSS et JavaScript pour présenter les produits de la mer de l’île d’Oléron. Le site propose une page de présentation et une page produits avec formulaire de contact.

## Structure

- `dist/index.html` : présentation de Fleur Océan
- `dist/produits.html` : huîtres, poissons, crustacés, coquillages et formulaire
- `dist/style.css` et `dist/script.js` : design responsive et animations
- `dist/assets/` : logo et polices intégrées

Le formulaire prépare un brouillon téléchargeable. Il ne transmet pas de message à un destinataire.
